# Quorum-sensing active particles with time-delayed feedback

Particle speed $v_i$ undergoes the underdamped dynamics
$$
\partial_t v_i = \gamma(v(\rho)-v_i) + \sqrt{2D_v} \zeta_i
$$
where $v(\rho)$ is the speed given by the quorum-sesing rule, and $\gamma$ controls how fast $v_i$ relaxes to $v(\rho)$.
